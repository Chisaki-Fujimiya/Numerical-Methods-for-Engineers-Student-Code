# Numerical-Methods-for-Engineers-Student-Code
Most (if not all) codes that will be used for a bachelor's numerical methods for engineers classes

FOR DIRECT DOWNLOAD: Install all methods on your devices and paste it to your Documents/MATLAB Directory.
FOR FOLDER DOWNLOAD: Install all methods on a folder and name the folder accordingly e.g. Solutions-to-Linear-Equations, Right click the folder and select Add path. 
HOW TO USE: Type your equation as a function of x in the f, then call the function with the following default parameters as given.

See numerical_methods.m for demonstration
